## About

IT student (Technician/Programmer track) at a technical school in Poland. Python is my strongest language and the core of my work: I build Telegram bots with aiogram, plus a Telegram client and web apps, taking each project from idea to deployment with tests and CI on my own Linux server. Over the last few years I have been broadening my stack with TypeScript, C++, C#, React, Next.js and PostgreSQL, and I have worked with various Linux distributions along the way.

## AI

AI is part of my daily workflow. I develop with **Claude Code** and **Google Antigravity**, write my own Claude Code skills, and run larger tasks through an orchestrator that coordinates several agents. I have worked with LLMs since their early days. Locally, I run models and agents in **LM Studio**, and in **ComfyUI** I work with image-generation models and have trained a LoRA for my own needs. I also test and build products on Ukrainian LLMs at **[Lapathoniia](https://lapathoniia.top)**, the first Ukrainian LLM inference provider with an OpenAI-compatible API (Lapa 12B, Mamay 27B, Rukopys OCR).

## Featured Work

### MZGram

[![GitHub](https://img.shields.io/badge/GitHub-repository-000000?style=flat-square&logo=github&logoColor=white)](https://github.com/dmytrokurochkin/MZGram-Desktop)
Unofficial Telegram client for desktop and Android, forked from Telegram Desktop and Telegram for Android. Keeps deleted and edited messages, ghost mode, message tools, 12 interface languages, and self-updating releases verified by SHA-256 checksums.

`C++` `Qt` `CMake` `GitHub Actions`

### Media-Downloader-Bot

[![GitHub](https://img.shields.io/badge/GitHub-repository-000000?style=flat-square&logo=github&logoColor=white)](https://github.com/dmytrokurochkin/Media-Downloader-Bot)

### Easy-Osint-Bot
